## Overview

- The main goal of the project is enabling low-power, long-range communication over ISM radio bands. [1]
- It transmits at power levels which do not require a license to use. [1]

## How it works

- Applications LoRa applications: Meshtastic — an open source mesh network protocol that uses LoRa flood messaging MeshCore — open source mesh network protocol that uses LoRa with more structured routing than Meshtastic LoRaWAN — a low-power, wide-area network (LPWAN) protocol that wirelessly connects battery-operated devices to the Internet. [3]
- Meshtastic is a LoRa-based mesh networking protocol and software platform. [1]
- This means that instead of all devices contributing to the mesh network, only repeaters can act as mesh nodes, retransmitting data. [2]
- MeshCore is a LoRa-based mesh networking protocol and software project created by Scott Powell in 2024. [2]
